# DeepSeek AI 身份与自动回复

本功能为 QQ 官方机器人增加 C2C 单聊 AI 自动回复。登录用户提供自己的 DeepSeek API Key；每个机器人只能保存一套独立身份、模型参数和回复策略。

## 能力范围

- 支持 `deepseek-v4-flash` 和 `deepseek-v4-pro`。
- 支持关闭或启用 DeepSeek 思考模式。
- 每个机器人一套唯一身份：名字、角色、关系、说话风格、回复长度、限制和高级提示词。
- 支持三种回复方式：
  - `auto`：优先引用触发消息，引用凭证失效时转普通主动消息。
  - `quote`：引用触发消息，可配置是否回退到普通消息。
  - `normal`：不携带 `msg_id`，直接发送主动消息。
- 使用最近成功的文本聊天作为上下文。
- 支持由模型选择管理员配置的 HTTPS 图片素材。
- 持久化 AI 回复任务，按 QQ 消息 ID 去重，并保证同一联系人顺序执行。
- 保存模型、Token 用量、发送模式、失败原因和任务状态。

当前 DeepSeek 文本模型不会理解用户图片，也不会生成图片文件。图片回复只会从管理员预先配置的素材中选择。

## 服务端环境变量

在 `backend/.env` 中配置：

```dotenv
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_REQUEST_TIMEOUT=45
AI_CREDENTIALS_SECRET=请替换为稳定的长随机字符串
```

`AI_CREDENTIALS_SECRET` 用于加密用户提供的 DeepSeek Key。生产环境必须单独配置并长期保持不变。修改该值后，数据库中原有的 Key 无法解密，需要用户重新保存。

未配置 `AI_CREDENTIALS_SECRET` 时会回退使用 `SESSION_SECRET`，这只适合兼容已有开发环境，不建议用于生产部署。

## 用户配置流程

1. 登录管理台。
2. 打开“功能开发 → AI 身份”。
3. 输入自己的 DeepSeek API Key，点击“验证并保存”。
4. 选择机器人，填写身份、模型、上下文和回复方式。
5. 可先使用“身份测试”验证模型输出，该操作不会向 QQ 用户发送消息。
6. 打开“启用自动回复”并保存。
7. 在 QQ 开放平台确认已开通 `C2C_MESSAGE_CREATE` 事件。

管理台启用 AI 时，会把 `C2C_MESSAGE_CREATE` 加入本地预期事件清单，但无法替代 QQ 开放平台的实际事件授权。

## Key 隔离

- Key 以登录用户 ID 为主键保存。
- 同一用户的多个机器人可以共用一份 Key。
- 每个机器人通过 `bot_id` 保存唯一 AI 身份。
- 非管理员只能访问自己名下的机器人。
- API 永远不返回 Key 明文或密文，只返回是否已配置和末四位提示。
- 保存前会调用 DeepSeek `/models` 验证 Key。

运行状态写入：

```text
/app/data/ai_companion.db
```

数据库应随现有 Docker 数据卷持久化，不应提交到 Git。

## 回复任务与幂等

收到 `C2C_MESSAGE_CREATE` 后，后端会在向 QQ 返回确认前：

1. 保存聊天消息。
2. 以 `(bot_id, QQ message_id)` 创建唯一 AI 任务。
3. 固定触发消息 ID、用户 OpenID 和当时的用户文本。

应用 Worker 从 SQLite 领取任务。领取使用事务，同一机器人、同一联系人的后续任务不能越过前一条任务。进程重启时，遗留的 `running` 任务会恢复为 `pending`。

每个机器人最多保留最近 2,000 条 AI 任务；聊天库继续按机器人保留最近 10,000 条消息。

## 引用与普通回复

引用回复使用创建任务时冻结的 QQ 消息 ID，而不是发送前再查询联系人的最新消息。这样用户连续发送消息时，AI 不会把第一条回答错误引用到第二条消息。

`auto` 和允许回退的 `quote` 模式，在 QQ 返回引用凭证过期错误时会重试普通主动消息。普通主动消息仍受 QQ 好友关系、用户主动消息开关和平台额度限制。

## 图片素材

图片素材包含：

- 唯一素材键，例如 `happy_cat`
- 显示名称
- 使用场景说明
- 公开可访问的 HTTPS 图片地址

模型只会得到素材键、名称和说明，不会得到任意文件系统权限。模型输出必须是 JSON：

```json
{
  "text": "给用户的回复",
  "image_key": "happy_cat"
}
```

后端会验证素材键属于当前机器人配置，然后：

1. 调用 QQ C2C 富媒体上传接口获取 `file_info`。
2. 使用 `msg_type=7` 发送图片。
3. 根据机器人回复模式携带或不携带触发消息的 `msg_id`。
4. 把图片发送结果写入聊天历史。

只允许不包含账号密码的 HTTPS URL。素材地址必须能被 QQ 服务端公开访问。

## 故障处理

- DeepSeek 或网络临时失败时，任务最多重试一次。
- 最终失败后，可向用户发送机器人配置的失败提示。
- 文本成功但图片失败时，文本保留成功，任务记录图片失败原因。
- 删除用户 Key 后，不再创建新的 AI 回复任务；已启用的机器人身份配置会保留。
- Key 因加密密钥变化无法解密时，页面会要求用户重新保存。

## 隐私提示

启用后，最近若干轮 QQ 单聊文本会发送给 DeepSeek 生成回复。部署方应在实际服务中向用户说明第三方模型处理、日志保留和隐私政策。

系统不会保存或展示 DeepSeek 的隐藏推理过程，只保存最终回复、模型名和 Token 用量。
